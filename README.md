## Contributing

Open an issue or pull request with the proposed entry, its category, a brief neutral description, and at least one primary-source URL. State whether it is live, testnet-only, planned, or uncertain, and include the date you checked the source.

Prefer official project links; keep descriptions factual and disclose material uncertainty. Do not include referral links, credentials, promotional performance claims, or unsupported affiliation claims. Preserve upstream attribution and licensing when proposing copied material.

Corrections to a TempoAtlas profile can also be submitted through [the site](https://tempoatlas.net/submit).
